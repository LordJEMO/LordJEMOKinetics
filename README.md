# LordJEMO Kinematics

A kinematics and trajectory system for Unity: kinetic managers, trajectory
groups, and Job System / Burst batch updates, with optional DOTS/Entities
integration.

## Status

Early, pre-release (`0.0.1`). API is unstable and expected to change.

## Package layout

- `Runtime/` — core kinematics API, manager, trajectories, jobs, and optional
  Entities components.
- `Editor/` — custom inspectors for the kinetic manager behaviours.
- `Tests/Editor/` — EditMode tests.
